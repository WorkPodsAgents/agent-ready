# Usual fixes

The usual change for each check. Read the code first; the cause on this site may differ.

| Check                                                                   | Usual fix                                                                                                                                                                                       |
| ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `missing_title`, `title_too_long`, `title_too_short`, `duplicate_title` | Set a distinct title per page in the head or metadata component: under 60 characters, main keyword first, brand last.                                                                           |
| `missing_meta_description`, `duplicate_meta_description`                | A distinct description per page that answers what the page offers.                                                                                                                              |
| `missing_h1`, `multiple_h1`                                             | One H1 per page, in the server HTML, naming what the page is.                                                                                                                                   |
| `missing_canonical`, `canonical_mismatch`                               | An absolute self-referencing canonical on every indexable page; point duplicates at the main version.                                                                                           |
| `noindex`                                                               | Remove the robots noindex (meta or X-Robots-Tag) from pages meant to rank; keep it where intended.                                                                                              |
| `non_200_status`, `broken_internal_link`                                | Restore the page, or 301 it to its closest live equivalent and update the links.                                                                                                                |
| `redirect_chain`, `internal_link_to_redirect`, `redirect_loop`          | Link straight to the final URL; collapse chains into one redirect.                                                                                                                              |
| `ai_content_requires_js`, `schema_requires_js`                          | Render the main content and JSON-LD on the server (SSR or static generation), not only in the browser.                                                                                          |
| `ai_crawler_blocked`                                                    | Change only the robots.txt lines or firewall rule that block search and answer crawlers (OAI-SearchBot, ChatGPT-User, Claude-User, PerplexityBot). Leave training-crawler choices to the owner. |
| `missing_schema`, `invalid_schema`, `schema_properties_missing`         | A JSON-LD block per page type with the required properties, values taken from the page.                                                                                                         |
| `missing_organization_identity`                                         | Organization JSON-LD on the home page with name, url, logo, sameAs and contact details.                                                                                                         |
| `missing_alt_text`                                                      | Alt text describing each meaningful image; empty alt for decoration.                                                                                                                            |
| `controls_unlabelled`                                                   | A visible label, `aria-label` or link text for each control.                                                                                                                                    |
| `webmcp_tool_incomplete`                                                | Complete the form's declarative WebMCP attributes: `toolname`, `tooldescription`, and `toolparamdescription` on each input.                                                                     |
| `llms_txt_invalid`                                                      | An H1 with the site name, a one-line summary, then H2 sections listing key pages with one line each.                                                                                            |
| `agent_manifest_invalid`                                                | Add the manifest's required fields, or move from ai-plugin.json to an MCP server card.                                                                                                          |
| `mixed_content`                                                         | Load every resource over https.                                                                                                                                                                 |
| `hreflang_*`                                                            | Every alternate lists every other, itself included, with valid codes and 200 targets.                                                                                                           |
| `slow_lcp`, `poor_cls`                                                  | Preload and size the main image, reserve space for late content, cut render-blocking scripts.                                                                                                   |
