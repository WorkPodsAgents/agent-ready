# Building the prompt panel

A good prompt is a question a real buyer asks an assistant before they know which brand to
pick.

## Sources, in order

1. The questions people search: the user's Search Console queries phrased as questions, if a
   Search Console MCP server is connected; People Also Ask for their main terms.
2. What the brand sells and to whom (its home and product pages).
3. Questions the user hears from customers.

Record the source of each prompt.

## Rules

- Never name the brand, its domains or a competitor in a prompt. Questions about the brand
  itself ("is Acme any good") measure reputation, not visibility; keep them in a separate list
  if the user wants them.
- Mix funnel stages: problem ("how do I stop blisters on long trail runs"), solution ("best
  trail running shoes for wide feet"), and decision ("trail running shoes with free returns in
  the UK").
- Write them as people type them: plain, specific, one question each.
- One market and language per panel. A second market is a second panel.
- 5 to 20 prompts. More prompts cost the user more time in Assist mode and more money with
  Cloro.
